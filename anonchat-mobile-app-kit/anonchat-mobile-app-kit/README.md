# MOBILE APP KIT — Anonymous Community Chat (React Native + Expo + TypeScript)

**How to use with Antigravity**
1. Unzip, open as workspace. Backend must be reachable from the phone/emulator (see AGENTS.md → API URL).
2. Paste `FIRST_PROMPT.md`.
3. Every later prompt: agent follows `.agent/workflows/review-prompt.md`; see `research/PROGRESS_LOG.md` for done/next.

| Path | Purpose |
|---|---|
| `AGENTS.md` | Stack, layout, commands, env, platform notes |
| `docs/API_CONTRACT.md` | Shared contract (same in backend/web) |
| `docs/ARCHITECTURE.md` | Navigation, state, auth storage, socket handling, notifications |
| `docs/DESIGN_SYSTEM.md` | Native design tokens, components, dark/light, motion |
| `docs/SCREENS_SPEC.md` | Every screen with data, states, validations |
| `docs/BUILD_PLAN.md` | Phased plan + acceptance criteria |
| `docs/TESTING.md` | Test plan (device matrix) |
| `docs/SECURITY_PRIVACY_CHECKLIST.md` | Pre-"done" checklist |
| `research/` | Living memory |
